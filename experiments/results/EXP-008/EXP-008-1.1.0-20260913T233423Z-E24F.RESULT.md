## Hypothesis

> Targeted likely-failure constraints provide at least as strong visible failure-mode control as a broad generic negative stack in a complex environmental portrait.

## Experimental contrast

The control used the broad generic negative stack:

> `Avoid bad anatomy, extra fingers, blur, artifacts, text, watermark, logo.`

The variant replaced only that clause with two targeted constraints:

> `Avoid distorted fingers around the tray and unintended readable text on the archival tags.`

The adult conservator, restoration studio, ceramic fragment and padded tray, hand visibility, archival work details, task/window lighting, layered composition, positive scene instructions, aspect ratio, and host generation settings were held constant.

## Interpretation

The targeted condition did not match the broad generic stack on the primary `targeted_failure_mode_control` dimension. It scored **1.00 lower** on that dimension and **0.375 lower overall**, so the run is classified **contradicts**.

The gap was not driven by malformed hands. Blind-review notes identified readable environmental signage/poster text in two targeted-condition outputs, while hand/object interaction remained technically clean. This matters because the targeted clause named readable text on archival tags specifically. The result therefore supports a narrower mechanism-level lesson: **targeted constraints can preserve the named scene and technical quality while leaving adjacent untargeted failure modes exposed**.

This does not establish that generic negative stacks are universally superior. It does show that the existing `prompt-targeted-constraints` rule is too broad to remain an automatic compiler default after this controlled Transfer Bench result.

## Pattern implication

`prompt-targeted-constraints` moves from `supported` to `mixed` and becomes non-compiler-eligible. The pattern remains in the registry as a context-dependent mechanism for future replication rather than being deleted.

The new failure mode is that narrowly scoped constraints may suppress or discourage the named failure while leaving semantically adjacent failure modes uncontrolled.

## Limitations

- Four replicates per condition are insufficient for a statistical-significance claim.
- Only one frozen blind-review score set was used, so inter-rater reliability was not measured.
- The exact host model snapshot and reproducible generation seed were unavailable.
- The finding is specific to `TB-A02`.
- The observed text failures were environmental signage/poster text rather than archival-tag text specifically.
- The broad control stack covered additional generic prohibitions, so the run compares broad generic coverage against narrow targeted coverage rather than equal-scope wording.
