# EXP-016 Result - Adversarial Implicit vs Explicit Multi-Reference Roles

**Run:** `EXP-016-1.1.0-20260917T001915Z-C4KW`
**Experiment version:** `1.1.0`
**Benchmark layer:** Transfer Bench
**Archetype:** `TB-A08`
**Model target:** `gpt-image-2`
**Model snapshot:** `unknown`
**Replicates:** 4 per condition
**Review protocol:** second-layer blind review with precommitted mapping
**Observed blind-score signal:** **supports**
**Final evidence classification:** **inconclusive**

## Hypothesis

> Explicit identity, outfit, and pose role declarations reduce cross-reference leakage relative to implicit multi-reference use when the references contain deliberately conflicting non-target attributes.

## Experimental contrast

The control used the same three frozen adversarial reference fixtures with an
implicit request to preserve the intended identity, outfit, and pose.

The variant changed only the opening reference-role instruction so that:

- Reference 1 controlled identity only.
- Reference 2 controlled garment construction and palette only.
- Reference 3 controlled joint arrangement and weight distribution only.
- Unrelated cross-role attribute transfer was explicitly prohibited.

Reference files, ordering, registered non-target conflict signatures, target
studio, lighting, full-body framing, anatomy requirement, garment silhouette,
and host-generation settings were otherwise held constant by the
preregistered design.

## Score-level interpretation

The frozen blind scores strongly favor explicit role declarations in this
adversarial three-reference context.

Mean `cross_reference_leakage_control` increased from **1.00** in the implicit
control to **3.50** in the explicit-role condition, an observed difference of
**+2.50**.

`reference_role_fidelity` also increased by **+2.50**, and
`semantic_compliance` increased by **+2.00**.

Every explicit-role replicate scored above every implicit-role replicate on the
registered primary dimension.

Technical cleanliness remained **5.00** in both conditions. Aesthetic quality
was slightly lower in the explicit-role arm, **4.75** versus **5.00**.

The registered score-level signal is therefore classified **supports**.

## Final evidence classification

EXP-016 is conservatively classified **inconclusive** at the
experiment-evidence level.

The available host-generation record does not independently establish, for
every individual output, that the intended task prompt and all three frozen
references were bound to that sample.

That provenance limitation does not erase the frozen blind-score separation,
so the result records the observed score signal separately as **supports**.
It does prevent this run alone from establishing the stronger causal
experiment-level conclusion.

## Compiler and pattern implication

The blind-score signal is useful positive evidence for explicit identity,
outfit, and pose role declarations when source references contain conflicting
non-target attributes.

However, because the final evidence classification is **inconclusive**, EXP-016
does not automatically change VisualPattern confidence, create a compiler rule,
or promote a golden benchmark.

The related registered patterns remain:

- `reference-identity-isolation`
- `reference-outfit-isolation`
- `reference-pose-isolation`

## Limitations

- Four replicates per condition are insufficient for a statistical-significance claim.
- Only one frozen blind-review score set was used, so inter-rater reliability was not measured.
- The exact host model snapshot and reproducible generation seed were unavailable.
- The finding is specific to `TB-A08` and the frozen adversarial `IDF-A02`, `OTF-A02`, and `POF-A02` fixtures.
- The available host-generation record does not independently verify the intended task prompt plus all three frozen reference bindings for every individual output.
- The control arm's zero observed overall sample SD describes this review sample only and does not imply zero underlying generation variability.
- Residual leakage remained in three of four explicit-role replicates, which scored 3 rather than 5 on the primary dimension.

## Next evidence needed

A follow-up replication should preserve the same frozen adversarial fixtures and
registered scoring protocol while capturing machine-verifiable per-sample
provenance that binds:

1. the exact task prompt,
2. Reference 1,
3. Reference 2,
4. Reference 3,
5. the resulting image hash.

A successful provenance-complete replication would allow the strong score-level
signal observed here to be evaluated without the current execution-binding
limitation.
