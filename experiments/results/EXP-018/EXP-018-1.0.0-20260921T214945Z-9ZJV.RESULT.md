## Hypothesis

> Explicit identity, outfit, and pose role declarations reduce cross-reference leakage relative to implicit multi-reference use in an independent adversarial three-reference fixture realization whose preregistered non-target conflict signatures are materially different from TB-A08/A02.

## Experimental contrast

The control used the same three frozen A03 adversarial references with an implicit
instruction to preserve identity, outfit, and pose without assigning a control
role to each reference.

The variant changed only the opening reference instruction to explicitly assign:

- Reference 1: identity only,
- Reference 2: outfit construction and palette only,
- Reference 3: pose mechanics only,

and explicitly prohibited unrelated cross-role transfer.

Reference assets, reference ordering, registered non-target conflict signatures,
studio target, composition, and other prompt text were held constant.

## Interpretation

In the TB-A09 independent A03 adversarial three-reference context, the explicit-role variant scored 2.25 versus 2.00 for the implicit-role control on cross_reference_leakage_control, a +0.25 variant-minus-control difference. Under the preregistered descriptive bands, -0.5 < delta < 0.5 is inconclusive. Across all 16 cross-condition pairs, variants won 6, controls won 3, and 7 tied. Neither condition was ceiling- or floor-saturated, and the locally verifiable execution and score-binding chain did not force a provenance downgrade. The run therefore remains inconclusive: the small positive descriptive direction does not establish the superiority hypothesis and is not a statistical-significance claim.

The result does not establish equivalence between implicit and explicit
reference-role wording. It also does not establish that explicit roles are
harmful. It shows that the strong positive separation previously observed in
the earlier adversarial fixture context did not reproduce strongly enough in
this independently constructed A03 realization to cross the preregistered
support threshold.

## Limitations

- Four replicates per condition are insufficient for a statistical-significance claim.
- Only one independent blind-review score set was used, so inter-rater reliability was not measured.
- The exact host model snapshot and reproducible generation seed were unavailable.
- The finding is specific to the TB-A09 independent A03 adversarial three-reference realization.
- The primary mean difference was small at +0.25 points and fell inside the preregistered inconclusive band.
- Primary scores were heterogeneous within both conditions: control scores were 5, 1, 1, 1 and variant scores were 2, 1, 5, 1.
- The operator-side treatment mapping had already been revealed before the independent reviewer scored the blind package. The reviewer attested that condition assignment was not seen before score freeze and that no outside experiment material was consulted.
- Accordingly, this run should not be described as using the older project's strict global review-freeze-then-reveal ordering; its blindness claim is reviewer-specific.
