## Hypothesis

> Explicit identity, outfit, and pose role declarations reduce cross-reference leakage relative to implicit multi-reference use when the references contain deliberately conflicting non-target attributes.

## Replication context

EXP-017 is the preregistered provenance-complete replication of EXP-016 under the registered AIPF execution-receipt workflow.
It preserves the same TB-A08 adversarial fixture set, prompt contrast, reference ordering, scoring dimensions, four replicates per condition, and freeze-before-reveal review protocol.

EXP-016 produced a strong positive blind-score signal but remained experiment-level inconclusive because its available host-generation record could not independently establish prompt-plus-reference binding for every sample.
EXP-017 adds the required task-commitment and execution-receipt workflow before importing each generated output.

## Experimental contrast

The control used the same three frozen adversarial reference fixtures with an implicit request to preserve the intended identity, outfit, and pose.

The variant changed only the opening reference-role instruction so that:

- Reference 1 controlled identity only.
- Reference 2 controlled garment construction and palette only.
- Reference 3 controlled joint arrangement and weight distribution only.
- Unrelated cross-role attribute transfer was explicitly prohibited.

Reference files, ordering, registered non-target conflict signatures, studio, lighting, full-body framing, anatomy requirement, garment silhouette, and host-generation settings were otherwise held constant.

## Score-level interpretation

Mean `cross_reference_leakage_control` increased from **2.00** in the implicit control to **4.25** in the explicit-role condition, an observed difference of **+2.25**.

`reference_role_fidelity` increased from **1.75** to **4.50**, a difference of **+2.75**.

`semantic_compliance`, `aesthetic_quality`, and `technical_defects` were all **5.00** in both conditions.

The replicate-level effect was not uniform. One control replicate scored 5 on the primary dimension, while one explicit-role replicate scored 2. The observed result is therefore an aggregate small-N signal rather than a claim that every explicit-role output dominates every implicit-role output.

The registered score-level signal is classified **supports**.

## Final evidence classification

EXP-017 is classified **supports** for the tested hypothesis in this specific TB-A08 context.

Unlike EXP-016, this replication used the preregistered task-commitment and execution-receipt workflow for every imported sample. That closes the local execution-binding limitation that forced EXP-016 to remain experiment-level inconclusive.

This does not create a statistical-significance claim, and it does not amount to provider-signed attestation of request metadata.

## Limitations

- Four replicates per condition are insufficient for a statistical-significance claim.
- Only one frozen blind-review score set was used, so inter-rater reliability was not measured.
- The exact host model snapshot and reproducible generation seed were unavailable.
- The finding is specific to `TB-A08` and the frozen adversarial `IDF-A02`, `OTF-A02`, and `POF-A02` fixtures.
- The registered review uses an ordinal 1-5 score scale.
- Semantic compliance, aesthetic quality, and technical cleanliness were ceiling-saturated at 5.00 in both conditions.
- Primary-dimension replicate performance overlapped between conditions.
- Provider-signed request metadata was unavailable.

## Next evidence needed

Useful follow-up evidence would replicate the role-separation mechanism across different identity, outfit, and pose fixtures, additional reference-conflict structures, and additional generation routes. A second independent reviewer would also help characterize inter-rater stability.
