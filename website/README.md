# Public Benchmark / Case Gallery

The public site is generated from project case records and optional **first-party** output images. It is not the V3.2 Internal Research Gallery.

```bash
python website/generate_gallery.py
```

The collected APC/FSC/GAC/LAC/LCC source corpus is never copied into this site. The separate internal gallery generator reads an external corpus path and is intended for private development/research use.
