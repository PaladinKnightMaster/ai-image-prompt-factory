# POF-A01 ? Neutral Contrapposto Pose Fixture

POF-A01 is a first-party synthetic pose reference used for controlled
multi-reference experiments.

Its role is pose only.

The faceless gray figure is intentionally stripped of identity, garment
design, palette, props, and environmental signals. The fixture exists to
communicate joint arrangement, contrapposto, weight distribution,
counterbalance, and floor contact.

The raster is stored privately. This public directory contains metadata
and frozen checksums only.
