# OTF-A01 ? Neutral Tailored Outfit Fixture

OTF-A01 is a first-party synthetic outfit reference used for controlled
multi-reference experiments.

Its role is outfit only.

The fixture uses a headless neutral mannequin so garment construction,
palette, seams, lapels, waistband, trouser width, and material separation
remain readable while identity, expressive pose, environment, and
storytelling signals are minimized.

The raster is stored privately. This public directory contains metadata
and frozen checksums only.
