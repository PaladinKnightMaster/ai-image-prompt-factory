# First-Party Benchmarks

`candidates/` contains benchmark plans owned by this project. `golden/` is intentionally empty until a candidate has a generated output, recorded generation metadata, evaluation, and human approval.

## Transfer benchmark layer

`transfer/` contains versioned first-party experimental archetypes used to test whether mechanisms discovered in the Isolation Bench transfer to richer production-like prompts.

Transfer archetypes are **not** golden candidates and are not promoted by successful experiments. They contain no private source prompt text or source images. See `docs/TRANSFER_BENCHMARK.md`.
