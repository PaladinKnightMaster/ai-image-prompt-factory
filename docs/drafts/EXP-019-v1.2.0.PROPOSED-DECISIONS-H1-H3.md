## H1 — Public provenance state

**Approved wording:**

> The public provenance state for EXP-019 v1.2 is
> `operator_evidenced_host_provenance`. Generation provenance rests on
> operator-controlled contemporaneous records and hash-bound operator
> attestations, not on authenticated host telemetry. Host-internal facts
> that the host interface does not expose are recorded as `not_observable`
> and no claim is made about them. A SHA-256 digest establishes byte
> integrity only; it does not establish authenticity, factual truth, or
> host observation. Aggregate counts of conflicts between model-generated
> statements and authoritative evidence are disclosed with every public
> result, and such conflicts are never resolved by soliciting further model
> statements.

**Status:** APPROVED by the experiment owner, 2026-10-22.

## H2 — No model metadata query, no metadata recovery

**Approved wording:**

> Production EXP-019 v1.2 intentionally omits any mandatory
> model-generated execution-metadata query and any metadata-recovery
> workflow. The model is never asked to report host-internal facts, and
> missing telemetry is recorded as `not_observable` and handled by the
> admission decision policy. Unsolicited model-generated statements, if
> preserved at all, are preserved verbatim as class-D evidence in an
> isolated namespace; they are never solicited to repair, replace, or
> corroborate authoritative evidence.

**Status:** APPROVED by the experiment owner, 2026-10-22.

## H3 — Terminal run disposition

**Approved wording:**

> Every formally completed or closed-incomplete EXP-019 v1.2 run receives
> exactly one terminal `run_disposition` checkpoint, using the existing
> public six-field checkpoint format. All started invocations must be
> accounted for in that event. An unresolved host outcome may be
> terminalized only through the authorized indeterminate-disposition
> procedure (`INDETERMINATE_FINAL` under the admission policy). An
> incomplete run is reported as incomplete; no partial run is presented as
> a completed experiment.

**Status:** APPROVED by the experiment owner, 2026-10-22.
