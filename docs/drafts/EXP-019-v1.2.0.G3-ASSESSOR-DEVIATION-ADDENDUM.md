## 1. Exact role statement (deviation)

**Deviation.** For this G3 nonexperimental pilot only, the requirement in
protocol `.r2` for a **separate independent human assessor** is replaced by
the following arrangement:

1. **Operator self-assessment** by the project owner (who is also the
   operator for this pilot); and  
2. **Supplementary ChatGPT image review** after generation, limited to
   post-generation commentary on prompt adherence and visual quality.

**This arrangement is not independent human assessment and must not be
described as such.** It does not establish personal blinding, independence
of review, or scientific peer assessment.

**ChatGPT review is advisory only.** It is limited to post-generation image
review and prompt-adherence / visual-quality commentary. ChatGPT review:

- does **not** establish host provenance;
- does **not** replace Q1–Q5 evidence capture;
- does **not** verify UI submission authenticity;
- does **not** authenticate class-C telemetry;
- does **not** authorize ADMIT, retry, or any scientific claim.

Operator self-assessment evaluates whether the fixed pilot procedure and
evidence rules were followed. It remains subject to the same abort and
honesty constraints as `.r2`.
