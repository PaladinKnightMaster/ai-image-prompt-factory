# Evaluation V3.1

V3.1 explicitly rejects a single “beauty score.”

## Independent axes

1. semantic compliance
2. aesthetic quality
3. historical/cultural integrity
4. art/material fidelity
5. identity fidelity
6. technical defects

Each axis has subdimensions. Historical review can separately flag wardrobe, hair/headwear, makeup/grooming, props, architecture/furniture, technology/writing, cross-cultural contamination, and evidence confidence. Material review can separately flag material identity, fabrication marks, surface/color behavior, structural behavior, artifact form/state, and aging.

## Failure taxonomy

The taxonomy includes route/lock/identity/reference leakage, anachronism/mixed culture, material/artifact failures, pose/hand/prop/lighting/composition issues, over/under-constraint, image-model limits, unsupported historical certainty, survival-bias confusion, evidence retrieval/source conflict, weak evidence promoted to canonical, gallery metadata failure, and regression baseline drift.

## Surgical revision

A revision plan has three responsibilities:

- name the failure
- name what must remain unchanged
- name only the failed dimensions to change

This prevents a material correction from unnecessarily changing identity, pose, wardrobe, or layout.
