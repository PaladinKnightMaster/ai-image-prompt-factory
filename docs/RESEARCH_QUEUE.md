## P1 - First transformation and art-method candidates

For each candidate, ask which fabrication, visible marks, material behavior, form, and failure tests distinguish it from existing modules. Candidate sources are museum object/conservation records, scholarly catalogues, and process documentation; verify authority and scope before use. Expected output is a source-backed method or transformation proposal with first-party test cases. All are **proposed**.

| Candidate | Specific discovery question | Evidence to seek |
| --- | --- | --- |
| Classical Greek marble bust | How do carving, form, finish, and original-versus-surviving appearance interact? | Bounded object records and conservation studies. |
| Bronze sculpture | Which casting, join, surface, and aging features matter by artifact state? | Process and object/conservation records. |
| Dunhuang/mineral-pigment mural | How should bounded site/period and pigment/ground evidence constrain a mural route? | Cave/period-specific catalogues and conservation research. |
| Edo woodblock print | Which block/printing constraints distinguish a print from flat illustration? | Print collections and process scholarship. |
| Blue-and-white ceramic | How do vessel geometry, cobalt application, glaze, and firing affect visible output? | Ceramic object and production records. |
| Chinese ink painting | Which support, brush, ink, and composition choices require separate controls? | Collection catalogues and technique scholarship. |
| Watercolor | Which paper, pigment, wash, and edge behaviors need explicit evaluation? | Material/process references and first-party tests. |
| Embroidery/textile | How do stitch, ground, thread, and construction affect form? | Textile object records and conservation studies. |
| Paper-cut/layered paper | What distinguishes cut silhouettes, stacked layers, and their physical shadows? | Process records and documented objects. |
| Manuscript miniature | Which page, pigment, border, and scale constraints matter in a bounded tradition? | Manuscript catalogues and conservation research. |
