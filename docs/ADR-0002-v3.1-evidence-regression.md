# ADR-0002 — V3.1 Evidence Graph and Regression Architecture

**Status:** Accepted  
**Version:** 3.1.0  
**Date:** 2026-09-07

## Decision

V3.1 extends the V3.0 compiler rather than replacing it. Historical/material assertions are represented as routed, versioned evidence claims linked to structured sources. Compatibility decisions consume those claims and historical strictness. Golden/regression cases pin evidence snapshots and prompt hashes. External sample images are indexed by metadata/hash rather than copied into the runtime.

## Adopt

- Small root skill + progressive disclosure.
- Structured semantic spec before natural-language prompt compilation.
- Explicit reference-role permission boundaries.
- Era/site/genre/art separation from V3.0.
- Evidence routing by pack/art method followed by contextual trigger filtering.
- Source quality and claim confidence as distinct concepts.
- Mode-specific compatibility actions (`accept`, `qualify`, `adapt`, `reject`, `allow_hybrid`).
- Survival-bias notes for original-versus-surviving appearance.
- Three regression layers: semantic, prompt, optional visual.
- Static gallery generated from case records.

## Modify

- V3.0 pack prose remains useful, but high-impact claims now point to versioned evidence IDs.
- Compatibility changes from mostly pack/rule checks to evidence-driven decisions.
- Case records gain evidence snapshots, compatibility audit, model/compiler/skill/source versions, and baseline references.
- Evaluation expands into subdimensions and explicit preserve/change revision plans.

## Reject

- One giant knowledge graph loaded for every request.
- One numeric “historical accuracy” score without claim/source traceability.
- Treating prompt-gallery examples as historical authority.
- Automatically republishing third-party sample images.
- Raw string diff as the only regression signal.
- Calling visual regression “passed” when no image was generated/evaluated.

## Why this is unique

The differentiator is not adjective quality. The system can trace a visual decision through `source → claim → compatibility action → prompt clause → case snapshot`, while keeping reference-role controls and material fabrication behavior in the same compilation path.

## Consequences

- Knowledge authoring is slower but testable.
- “Unknown” and “interpretive” remain valid outputs rather than failures to be hidden.
- Existing V3.0 cases compile with richer diagnostics instead of requiring a wholesale rewrite.
- Sample corpora become useful for regression discovery without becoming a licensing liability.
