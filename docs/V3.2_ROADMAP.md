# Recommended V3.2 Milestone

## Evidence Density + Real Visual Regression

V3.1 creates the provenance/regression machinery. The highest-leverage V3.2 work is to **densify a few domains and attach first-party generated visual baselines**, not expand worldwide.

Priority:

1. Tang subperiod/social-role wardrobe/hair/object graph.
2. Cave-level Dunhuang packs with date/dynasty/pigment/restoration state.
3. Ming grounded-Wuxia object/wardrobe/architecture compatibility.
4. Edo Arita/Hizen ceramic chronology + ukiyo-e production variants.
5. Greek/Roman sculpture chronology, polychromy, portrait and armor/dress distinctions.
6. First-party GPT Image 2 outputs for selected golden/regression cases with evaluator records.
7. Optional perceptual image hashing and visual-difference triage.
8. Evidence-source conflict fixtures and claim deprecation/version migration tools.

Do not add another large prompt library until these baselines can tell us whether new knowledge actually improves or harms outputs.
